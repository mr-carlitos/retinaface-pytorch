# Source code of Carlos Kirchdorfer's master's thesis

This README provides a quick overview of the source code for the master thesis 'Going Beyond Feature Pyramids in Face Detection'. 
The implementation is based on the work of the GitHub user biubug6 and the base repo is the following one: https://github.com/biubug6/Pytorch_Retinaface. The original RetinaFace code, as provided by the RetinaFace authors, can be found here: https://github.com/deepinsight/insightface/tree/master/detection/retinaface.

| modules                                             | biubug6/Carlos | Very important core network modules can be found here. The overall RetinaFace framework code can be found in retinaface.py. The classical FPN and SSH context module code can be found in net.py. The alternative neck architectures that use transposed convolution and pooling (RQ2) are provided inside poolingarchitecture.py. For the model variants that use cross-scale attention (RQ3), please consult attentionarchitecture.py. positionalencoding_QKV.py provides classes for sinus/cosinus fixed positional encodings and learned positional embeddings. directinteraction_attentionarchitecture.py can be ignored, as it investigated alternative cross-scale attention mechanisms, without being successful                                                                                                                                                                                                                                                                                                                                                                                    |
| resnet-50-11k                                       | Carlos | Since the implementation from biubug6 worked with the ImageNet-1k ResNet provided by PyTorch, while the RetinaFace authors stated that they used a ImageNet-11k-based ResNet instead, I imported / adapted the ImageNet-11k ResNet backbone from MXNET, provided by the authors.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| utils                                               | biubug6/Carlos | Folder which containts a couple of util / helper functions. I mostly just reused what was provided by biubug6, but I added / changed some things and functions, such as box voting (box_voting.py) or clip_boxes() (function inside box_utils.py).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| widerface_evaluate                                  | biubug6/Carlos | After having obtained the prediction .txt files (see create-predictions-txtfiles/test_widerface_as_mxnet), the task is to get the evaluation results by comparing the predictions with the ground truth information for each validation subset. The code in this folder does this: The ground_truth folder contains the ground truth data (MATLAB files). evaluation_mogface_final.py is responsible for obtaining the final AP and mAP evaluation results for one specific model variant. evaluation_mogface_final_allmodels.py does the same as evaluation_mogface_final.py, but does it for a group of model variants that are placed in the same folder and then also computes the Precision-Recall plots. fdrpi_specific.py computes the TPDR-FPDPI evaluation results (and plot) for a specific model variant. fdrpi_final_allmodels.py calculates the TPDR-FPDPI evaluation results for a group of model variants and then also provide TPDR-FPDPI plots for this group. bin-specific-detection.py computes and plots per-bin recall on WIDER-Face Hard validation subset at 0.90 / 0.95 confidence. |
